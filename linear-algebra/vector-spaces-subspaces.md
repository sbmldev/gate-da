# Vector Spaces and Subspaces

```{note}
**Definition**

A vector space is a collection of objects called vectors combined with a set of numbers called scalars.
```

Two primary operations are defined on these elements:
1. Vector addition $(u+v)$, and
2. Scalar multiplication $(c \cdot v)$

For a vector $V$ to qualify as a vector space, these operations must always stay inside the set (**closure** property) and satisfy a standard set of algebraic rules known as **axioms**.

```{note}
**Key Axioms**
**1. Associativity of Addition:** $(u+v)+w = u+(v+w)$
**2. Commutativity of Addition:** $u+v = v+u$
**3. Additive Identity (Zero Vector):** There exists a zero vector $0 \in V$ such that $v+0 = v$
```
